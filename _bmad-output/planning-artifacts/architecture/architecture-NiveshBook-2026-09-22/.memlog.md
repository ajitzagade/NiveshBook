- (constraint) Brownfield sweep of apps/web, apps/api, packages/core|types|ui found the tooling skeleton (Turborepo, pnpm workspaces, @niveshbook/* package naming, TypeScript, Next.js App Router, Fastify) is sound and should be kept -- but the domain model (packages/types Portfolio/Investment/Money-as-number, packages/core portfolio.ts return-calculation helpers, packages/ui PortfolioSummaryCard) is a generic personal-investment-portfolio demo, not the NiveshBook partner/sub-partner/project domain from the PRD. Money.amount is a plain JS number, which directly violates PRD SS5's decimal-safety NFR. This is throwaway demo content to be replaced, not a foundation to extend.
- (version) Web-verified 2026-09-22: Next.js latest stable is 16.2.10 (scaffold pinned at 14.2.15, two majors behind); Fastify latest major is v5.12.5 (scaffold already on ^5.0.0, current); React scaffold on 18.3.1 vs Next 16's expected React 19 line.
- (constraint) User requires infra to be fully free for at least the first year, until 2+ paying clients exist. This is a hard constraint on hosting/DB/cache choices, researched live (2026-09-22): Vercel Hobby free (100GB bandwidth, 1M function invocations, 10s max duration, but ToS restricts Hobby to non-commercial use -- flagged as a real risk, not just a technicality); Neon Postgres free tier (100 CU-hours/mo, 0.5GB storage per project, scales to zero); Render free web service (persistent Node process, but cold starts after inactivity); Railway and Fly.io no longer have real free tiers in 2026.
- (question) Fork surfaced by the free-infra constraint: keep apps/api as a separate Fastify service (needs Render free w/ cold starts, or a paid host) vs collapse the API into Next.js Route Handlers in apps/web so the whole product runs on one free Vercel Hobby deployment + Neon free Postgres, with sessions stored in Postgres instead of Redis (avoids needing a third free-tier service). Leaning toward the collapsed/single-deployment option for cost and operational simplicity at this scale; presented to user for confirmation, not silently decided.
- (event) User also asked for proper visual mockups before proceeding further -- pausing architecture spine drafting to produce mockups first (via Artifact), since Design & Feel (PRD OS6 / Open Question 1) has no visual reference yet and the user wants to react to something concrete before architecture/build continues.
- (decision) User confirmed: collapse apps/api into Next.js Route Handlers in apps/web; single Vercel Hobby (free) deployment + Neon Postgres (free); sessions stored as Postgres rows (no Redis). Free-infra target: at least through year 1 or until 2+ paying clients exist.
- (event) Produced 3 light-theme visual-design options as an Artifact mockup (Ledger: ink+turmeric serif/sans; Slate: cool slate-blue+sage all-grotesk; Harbor: navy+emerald slab-serif) per explicit user request for multiple decent, non-dark, non-bright-color options. Awaiting user pick before this becomes the packages/ui design system -- not blocking architecture spine drafting, which proceeds now.
- (event) Adversarial review found 12 real holes (collection-scoping in authorize(), rounding/remainder policy, Share % column-vs-table scope + versioning, personId identity ambiguity, reversal cascade undefined, AD-6 non-composable transaction breaking FR-27 multi-destination atomicity, cached-session-permission risk, idempotency uncovered, concurrency/lost-update risk on Available Balance, AD-9 overclaiming its own enforcement, AD-2 lacking teeth against parseFloat, and 3 Capability Map inconsistencies). All 12 fixed: AD-1/2/3/4/5/6/9 rewritten, AD-10 added (concurrency locking), Capability Map corrected. Lint clean after fixes.
- (event) spine finalized
- (decision) Design direction resolved: user rejected the 3 muted-palette options (too bright/hard on the eyes) and supplied a concrete reference screenshot (clean SaaS-dashboard style -- light cool-grey canvas, white cards, blue primary accent, green/red/teal/violet status chips, colored icon badges in nav). Mockup rebuilt to match; this supersedes the Ledger/Slate/Harbor Deferred item and becomes the packages/ui token direction.
